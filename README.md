# Gender Classification
In this project, I used a facial image dataset to build a Convolutional Neural Network(CNN) model for gender classification. The model predicts whether a given face image belongs to male or female.
In this project, to predict the gender I used the CNN model using the Sequential and also other techniques like Conv, Maxpool. After training the CNN model, I tested it by providing new image input and based on that input the model predicts the gender.
The dataset used for this project consist of facial images and was downloaded from kaggle.

# Installation
To run this project you need to download jupyter notebook and in the notebook you need to import various libraries like trnsorflow, numpy, matplotlib and in tensorflow various libraries need to be import like Sequential, MaxPool etc.

# Usage
In line 29 you can put the path of any images of male and female images for an prediction.
